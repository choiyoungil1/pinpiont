# PinPoint MVP - 실행 방법

## 파일 구조
```
pinpoint/
├── index.html       - 랜딩 페이지
├── dashboard.html   - 메인 대시보드 (카테고리형)
├── subsidy.html     - 고용 지원금 사다리타기
├── cert.html        - 기업 인증 혜택 안내
├── quiz.html        - 퀴즈 & 뱃지
├── knowledge.html   - 역량강화 카드
├── style.css        - 공통 스타일 (다크톤 골드 테마)
└── app.js           - 공통 로직 (데이터 포함)
```

## 바로 열기
`index.html` 파일을 더블클릭하거나 크롬 브라우저로 열면 됩니다.

## 구현된 기능
- ✅ 랜딩 페이지 (서비스 소개, 요금제)
- ✅ 메인 대시보드 (7개 카테고리 카드)
- ✅ 회사 정보 등록 (임원 정보 포함, localStorage 저장)
- ✅ 고용 지원금 사다리타기 (단계별 질문 → 결과)
- ✅ 기업 인증 정보 카드 (혜택, 기준가, 전문가 연결)
- ✅ 퀴즈 (카테고리별 필터, 정답/오답, 통계)
- ✅ 뱃지 시스템 (퀴즈 정답 시 자동 획득)
- ✅ 역량강화 카드 (읽음 표시, 진행률)
- ✅ 면책 고지 (모든 페이지)
